## Project: Super Caculator

![Build Status](https://img.shields.io/badge/build-passing-green.svg(

This project is a simple calculator app build with Python. It allows users to perform basic arithmetic operations like addition, subtraction, and divison.

## Instalation

Before you start, make sure you have the following prerequisites:
| Requirement | Version |
|---|---|
| Python | 3.x
| Pip | latest |

To install the project, clone the repository:
```bash
git clone https://github.com/username/super-caculator.git
cd super-caculator
```
Then, install the dependencies:
```bash
pip install -r requirements.txt
```
Note: If you encounter an error, try running `sudo apt-get update` before installing.

## Usage

To run the application, follow theses steps:
1. Open your terminal
- Navigate to the folder
2. Run the main script:
    ```bash
    python main.py
    ```
Here is a code snippet showing how it works:
```python
def add(a, b)
    return a + b

result = add(5, "10")
print(f"The result is {result}")
```
